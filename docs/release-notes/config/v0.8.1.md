**A section write announces every section it moves, and the quarantine prune touches only this
file's own copies.**

**Released** 2026-09-29

**Patch.** Nothing a consumer compiles against moves.

## Fixed

- A sectioned store's `Changed` event fires for every section whose held bytes a write moves, not
  only the one being written. A hand edit to a sibling section that the write takes in is no longer
  lost to a later reload or watcher.
- The quarantine prune in both stores matches only this file's own stamped copies. A file whose name
  starts with this file's stem and a dot keeps its copies, and this file keeps its newest.
- Adding the first section to a document with no keys inserts before the closing brace, so a comment
  standing alone there survives the write.
- An unread variable is removed and comments state present facts.
