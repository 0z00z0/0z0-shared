**The configuration packages move to .NET 11.**

**Released** 2026-11-19

**Minor, breaking.** The packages target `net11.0` instead of `net10.0`. No type, member or behaviour changes. `ZeroZero.Config`, `ZeroZero.Config.Sections` and `ZeroZero.Config.Watch` release together.

## What a consumer has to change

- Target `net11.0` and build with the .NET 11 SDK, 11.0.100 or later. A project still on `net10.0`
  cannot take this release.
- **The .NET 11 desktop runtime is required on the end user's machine** for a framework-dependent
  application; a self-contained publish carries it.
