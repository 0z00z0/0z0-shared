**The family's pins list the two packages the components' texts bring.**

**Released** 2026-10-23

**Patch.** Two pins are added; no property, target or existing pin changes, and nothing in a
consuming project file has to change.

## Added

- `Microsoft.Extensions.Localization.Abstractions` 10.0.12, which arrives through
  `ZeroZero.Primitives`. Its `IStringLocalizer` is the interface an application implements to
  override or translate a component's texts.
- `MessageFormat` 8.0.0, which arrives only through `ZeroZero.Mqtt` for its counted texts. The
  package is MIT-licensed by its source repository and ships no licence text, so an application
  that ships the MQTT component carries the notice itself.

Both are listed in the pin table in `docs/consuming.md`.
