**The signing script recognises an untrusted root on a Windows set to any language.**

**Released** 2026-10-11

**Patch.** No property, target or pinned version changes.

## Fixed

- `Sign-Executable.ps1` compares the signature's status message with the system's own message for
  an untrusted root, which Windows localises the same way, instead of matching English words. A
  self-signed signature on a non-English Windows is recognised as such.
