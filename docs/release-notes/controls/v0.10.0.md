**One fixed-width popup that sizes itself to its content, and Escape closes the text prompt from
any control.**

**Released** 2026-10-11

**Minor, additive.** One type is added. Nothing an application already calls behaves differently,
apart from the prompt's Escape key below. Takes `ZeroZero.Win32` 0.9.2 and `ZeroZero.Primitives`
0.8.0.

## Added

- **`ContentSizedPopup`** — the chrome and sizing a fixed-width popup window needs, in one place.
  `Attach(window, content, contentWidth, escape)` sets the chrome, binds Escape on the content's
  root to `escape`, and fits the window to the content now and on `Loaded`; `Fit()` refits after the
  content changes. A first measure of zero opens the window at 200 units. A fit after the window
  has closed does nothing. The About window, the update window and the text prompt are built on it.

## Changed

- `TextPromptWindow` cancels on Escape from whichever control has focus, as the About and update
  windows do. It cancelled only while the text field had focus.
