**The controls' own texts are translatable, with Norwegian built in.**

**Released** 2026-10-23

**Minor, additive.** Two types are added. Existing code compiles and behaves as before in English.
Takes `ZeroZero.Primitives` 0.9.0 and `ZeroZero.Win32` 0.9.2.

## Added

- **`ControlTexts.Strings`**, one `IStringLocalizer` for the whole application, asked first for every
  text the controls write. Null, the default, asks nothing. Info buttons are also created inside
  other components, where an application cannot reach them, so this is the one place to set it:
  once at start-up, before the first window opens.
- **`ResourceMapStringLocalizer(string library)`**, an application's own `.resw` entries as an
  `IStringLocalizer`, for a library that asks the application's resources before its own. An index
  that cannot be opened leaves fewer places to ask, never an exception.
- Texts in `Texts.resx` (en-GB) with Norwegian bokmål in `Texts.nb.resx`, packed as
  `lib/<tfm>/nb/ZeroZero.Controls.WinUI.resources.dll`.

## Changed

- An info button's screen-reader name, "More information" or "More information about {subject}",
  follows the UI culture.
- `TextPromptOptions.Cancel` defaults to the controls' own "Cancel" in the UI culture. A value the
  caller sets is used as given.

## What a consumer has to change

Nothing. An application that translates its interface sets `ControlTexts.Strings` once at start-up
if its own wording should replace the controls' texts.
