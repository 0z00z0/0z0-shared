**Closing a text prompt with Alt+F4 no longer crashes the process.**

**Released** 2026-09-29

**Patch.** Nothing a consumer compiles against moves.

## Fixed

- `TextPromptWindow` collapses the field's selection whenever the window closes. A prompt closed
  with Alt+F4, or any other way, with the field untouched ended the process with an access
  violation.
- `TextPromptWindow.ResizeToContent` lays out before measuring, rounds the height up and caps it at
  the work area, as the other two sizing routines do.
- `SettingsRow` and `SettingsSectionHeader` hide the info bubble when `Info` is blank or whitespace.
- Comments and the controls guide state traps as present facts.
