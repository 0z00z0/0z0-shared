**The first release of the primitives foundation assembly.** `ZeroZero.Primitives` holds the few
pieces several components need and none of them owns: the log sink every component writes through,
the reader of the version an assembly actually carries, the gate that collapses a burst of signals
into one pass, and the build files that stamp the commit into that version. Plain `net10.0`, no
package references, no project references.

**Take it directly only to get the stamp.** Every other component that needs it brings it along, and
a transitive arrival is deliberately not restamped — the build files are packed to `build\` rather
than `buildTransitive\`.

## What is in the package

- **`ILogSink`** — two methods, `Info(string)` and `Error(string, Exception?)`, and nothing else.
  The exception is nullable, so a component can report a refusal it has no exception for.
  **`NullLogSink.Instance`** is the shared no-op every component defaults to, so a host can tell
  "nothing wired" from "wired to something quiet" by reference.
- **`AssemblyVersionText`** — `Read(Assembly)` returns the informational version the loaded assembly
  reports, falling back to the plain assembly version, and **returns the empty string when the
  assembly carries neither**. `ForDisplay(string)` trims the commit to seven characters for an About
  box, and only when what follows the `+` is longer than seven characters and is entirely ASCII hex;
  anything else passes through untouched.
- **`CoalescingGate`** — `Signal()`, `BeginPass()`, `ShouldRepeat()`. Two flags under a lock:
  `Signal()` returns true only to the caller that must start the loop. It schedules nothing and owns
  no thread; the caller owns the loop and the work.
- **The source-revision stamp** — `build/ZeroZero.Primitives.props` and `.targets`, which run
  `git rev-parse` in the consuming project's directory and put the short commit into
  `AssemblyInformationalVersion`.

## What the stamp does and does not guarantee

The stamp runs in the **consuming project's** directory and continues on error. Restoring from a
package cache — which is in no repository — finds no git, so the .NET SDK's own forty-character
stamp stands; a machine with no git at all stamps nothing and the assembly reports the bare number.
That is why `ForDisplay` exists, and why `Read` can legitimately return an empty string. Do not print
either unguarded.

A sibling `ProjectReference` carries no build files at all, so that route imports the targets by
path.

## Where this code came from

The log sink, the gate and the version reader were inside `ZeroZero.Mqtt` and are now here, so that
a component with no interest in MQTT can take them. Two consequences reach a consumer of the MQTT
module, and they are recorded in that component's own notes: `IMqttLog` and `NullMqttLog` are gone in
favour of `ILogSink` and `NullLogSink`, and `CoalescingGate` changed namespace.

## Why 0.7.0 and not 0.1.0

Every component in the family starts at 0.7.0. Up to and including 0.6.0 one number released every
package together; 0.7.0 and above means a component releases on its own, and the shared floor keeps
the two eras from overlapping.
