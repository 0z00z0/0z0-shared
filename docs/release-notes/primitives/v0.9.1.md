**A host text that cannot be formatted with a component's arguments gives way to the component's own text, never an exception.**

**Released** 2026-10-23

**Patch, additive.** Nothing an application already calls is removed. Takes
`Microsoft.Extensions.Localization.Abstractions` 10.0.12.

## Fixed

- `LibraryStringLocalizer`'s indexer with arguments never throws. A host text the arguments cannot
  fill, such as `{1}` where one argument is given or a pattern with an unclosed brace, is ignored
  and the component's own text is formatted instead. A component text that fails too comes back
  unformatted.

## Added

- `Format(name, formatter)` applies any formatter to the text under the same rule, for a component
  whose texts are not `string.Format` patterns.
- `Log`, an optional `ILogSink`, is told once per key when a text cannot be formatted.

An application with its own texts for a component checks the log for such a key and corrects or
deletes that text.
