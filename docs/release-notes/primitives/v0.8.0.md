**A file of moments, read and written in one place.**

**Released** 2026-10-11

**Minor, additive.** One type is added. Nothing an application already calls behaves differently.

## Added

- **`TimestampListFile`** — `Read(path)` and `Write(path, stamps)` for a file of moments, one per
  line in the round-trip (`O`) form with the offset.
  - `Read` returns the moments in file order, nothing for a missing file, and drops a line that does
    not parse.
  - `Write` replaces the file and creates its folder.
  - A file that cannot be read or written throws the file system's own exception. It never sorts,
    prunes or locks; two processes writing one file at once is the caller's to prevent.

The lifecycle relaunch limit and the startup watchdog's restart limit are counted in this file from
lifecycle 0.7.2 and startup 0.8.3.
