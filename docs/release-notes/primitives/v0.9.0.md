**A component's texts come from its own resource files, with the application's localizer asked first.**

**Released** 2026-10-23

**Minor, additive.** One type is added. Nothing an application already calls behaves differently.
Takes `Microsoft.Extensions.Localization.Abstractions` 10.0.12.

## Added

- **`LibraryStringLocalizer(ResourceManager resources, IStringLocalizer? host = null)`**, the
  `IStringLocalizer` every component with texts reads them through.
  - The host's localizer is asked first. An answer it does not find, or a blank one, counts as
    missing, never as an empty text.
  - Otherwise the component's own `.resx` answers for the UI culture, falling back to its neutral
    en-GB. A key nothing declares renders as the key itself, marked not found.
  - The UI culture picks the words. A number, size or time inserted into a text follows the regional
    format, `CurrentCulture`, with the person's own changes such as a comma as the decimal
    separator. A port or a version is formatted invariantly by the component that inserts it.
  - `GetAllStrings` answers every key the component declares, each as the indexer answers it.

The layout every component's texts follow — neutral file, translations as satellite assemblies,
context notes for the translator — is in `docs/zerozero-primitives.md` under Texts.
