**The default master switch title reads "Remote control (MQTT)".**

**Released** 2026-10-25

**Patch.** Only text values change; no key, identifier, setting or API moves. Takes
`ZeroZero.Primitives` 0.9.1, `ZeroZero.Config` 0.9.0, `ZeroZero.Controls.WinUI` 0.11.0 and
`MessageFormat` 8.0.0.

## Changed

- The default title of the master switch card reads "Remote control (MQTT)" in English and
  "Fjernstyring (MQTT)" in Norwegian, so the acronym follows the plain words.

An application that sets its own `PublishTitle` keeps its own text.
