**The module's texts come from resource files with Norwegian built in, the settings panel redraws the
moment the link changes, and it can offer to remove the published device.**

**Released** 2026-10-23

**Minor, breaking.** The string-source types are removed in favour of `IStringLocalizer`, and
`SummariseBroker` returns a record. Takes `ZeroZero.Primitives` 0.9.0, `ZeroZero.Config` 0.9.0,
`ZeroZero.Controls.WinUI` 0.11.0 and `MessageFormat` 8.0.0.

## Added

- Texts in `ZeroZero.Mqtt`'s `Texts.resx` (en-GB) with Norwegian bokmål in `Texts.nb.resx`, packed as
  `lib/<tfm>/nb/ZeroZero.Mqtt.resources.dll`, each entry with a context note for the translator. The
  UI culture picks the language. `AgeMinutes`, `AgeHours`, `AgeDays` and `SummaryPublish` are ICU
  MessageFormat patterns whose plural follows the UI culture's rules; every other text is a .NET
  format string.
- **`MqttPanelSetup.OfferRemoval`**, off by default. On, the panel ends with a section whose button
  asks for confirmation, runs the connection's own `RemoveDeviceAsync`, writes publishing off through
  the store and raises `ConnectionChanged`. It needs the setup built from the connection; `Initialise`
  refuses it otherwise. The button is live only while publishing is on, the link is connected and no
  removal runs.
- **`MqttPanelSetup.NotifyConnectionStateChanged()`**, callable from any thread, for a host that builds
  the setup by hand. A setup built from the connection follows its state by itself.
- **`MqttBrokerSummary(Text, DetectedAt)`**, the closed Broker line as plain text plus the position
  straight after each value that was found rather than set by hand.
- The What to publish heading has the module's own info text.

## Changed

- **A host's texts arrive as an `IStringLocalizer`**: `MqttPanelSetup.Strings`, the `MqttPanelText`
  constructor, the `MqttBrokerEdits` constructor and `MqttIdentity.Validate` take one, asked first by
  key. `MqttPanelText.Strings` is an `IStringLocalizer`. With no localizer on the setup the panel asks
  the application's own `.resw` first, as before.
- **`MqttPanelText.SummariseBroker` and `MqttStatusText.SummariseBroker` return `MqttBrokerSummary`.**
  The panel draws a small magnifier in the line's own text colour after each found value, in place
  of the "(detected)" text; the Broker heading's info bubble explains the mark, and a screen reader
  hears "detected value" after each marked value.
- The Connection row, the Broker in use row and the closed Broker line redraw the moment the link
  changes while the panel is shown.
- Panel texts use whole words ("minutes ago", "for example", "ID"), the discovery-prefix info names
  no product, and the publish switch's info says that switching off marks the device offline at the
  broker before the connection closes.

## Fixed

- A remembered endpoint without its fifth field, `encrypted`, was refused for good under Automatic
  encryption. It now applies: its port and transport lead the search in both schemes, encrypted
  first, and nothing reports the encryption in force from it.

## Removed

- `IMqttStringSource`, `MqttStrings` with its `Default` and `Builtin` table, `MqttResourceMaps` and
  the panel's resource-strings class.
- The keys `AgeHour` and `AgeDay`; the singular is a branch of `AgeHours` and `AgeDays`.
- `SummaryDetected`, and the `.resw` in `ZeroZero.Mqtt.WinUI`.

## What a consumer has to change

- An application that implemented the module's string-source interface implements
  `IStringLocalizer` instead and passes it as `MqttPanelSetup.Strings`. `Strings.Get(key)` becomes
  `Strings[key].Value`, and `Strings.Format(key, args)` becomes `Strings[key, args].Value`.
- An application that read the built-in table as a template for a translation reads `Texts.resx` in
  `ZeroZero.Mqtt` instead.
- An override of `AgeHour` or `AgeDay` moves into `AgeHours` and `AgeDays`, written as ICU plural
  patterns.
- A call to `SummariseBroker` reads `.Text` from the result.
- A host that builds `MqttPanelSetup` by hand, without the connection, calls
  `setup.NotifyConnectionStateChanged()` on every connection state change.
- An application that wants the removal card sets `OfferRemoval = true` on a setup built from the
  connection.
- `PublishGroupsInfo` may be dropped: the module has its own text for that heading.
- The endpoint memory stores all five fields. An entry without `encrypted` is accepted, but the
  encryption in force is then never reported.
- Any application-side copy of `SummaryDetected` is deleted.
- Old MQTT entries in the application's own `.resw` that share a key with the module are deleted.
  The application's resource map is asked before the module's texts, so such an entry overrides the
  module's wording and its Norwegian.
- Every application that ships the module carries the MIT notice of `MessageFormat`, copyright 2014
  Jeff Hansen, for example in its About box's list of external libraries: the package ships no
  licence text.
