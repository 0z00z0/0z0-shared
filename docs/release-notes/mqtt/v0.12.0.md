**Every entity can carry a fixed description the receiver shows as an attribute.**

**Released** 2026-10-11

**Minor, additive.** Nothing changes for an entity that declares no description.

## Added

- `MqttEntity.Description`, on all seven component types. Set, the component entry gets
  `json_attributes_topic` pointed at the device's availability topic and a
  `json_attributes_template` that returns `{"description":"…"}`, so the receiver shows the text as
  the entity's `description` attribute. No topic is added and nothing new is retained.
- An entity declaring a `Description` and a `json_attributes_*` key (full or abbreviated) in
  `Extra` is refused by `MqttEntitySet` with an `ArgumentException`.
