**The Broker section's closed line now says when the connection accepts any certificate the broker
presents.** Every other trust mode reads exactly as it did on 0.8.0.

**Released** 2026-09-28

**Patch.** Nothing is removed or renamed, no member changes signature in a way that breaks a
caller, and the three modes that still prove which machine answered read the same line, character
for character, as before. A consumer that changes no code sees no difference at runtime unless it
has already chosen the fourth mode.

## What the line said, and what it says now

Before this release the closed Broker line named the host, the port, the transport and whether the
link was encrypted — and nothing about which certificates it trusted. A broker that accepted any
certificate at all read identically to one pinned to a single trusted machine, until the section was
opened and the Certificate trust row read.

The line now carries one more clause, and only under that one mode — `broker.example.com · 8883 ·
TCP · encrypted — any certificate accepted`.

The platform's own trust, a pinned thumbprint and a pinned certificate add nothing: each of those
still proves which machine answered, so the line is unchanged for them, in every state — set by
hand, detected, or with no broker configured at all.

## Where it is composed

`MqttPanelText.SummariseBroker` takes a fourth parameter, `MqttCertificateTrustMode trust`, and
`MqttStatusText.SummariseBroker` carries it through its static facade. The new clause wraps the
finished line through its own string key, `SummaryBrokerTrustAny`, rather than adding a fifth
argument to `SummaryBroker` — so the four-part line a translation already reorders is untouched, and
the wrapping key is free to place the clause wherever a translation reads best.

`MqttSettingsPanel` reads the trust mode from the saved settings, the same source the rest of the
line already reads host, port, transport and encryption from, and passes it through when the
Broker section's summary is refreshed.

## Unchanged

The four trust modes themselves, `MqttCertificateTrust.Accepts`, the endpoint search, the Status
rows, the publish-section summary, and `ZeroZero.Mqtt.Discovery`. `ZeroZero.Mqtt.WinUI` carries no
other change.
