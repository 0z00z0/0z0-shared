**The About card draws its own frame.** A rounded stroke around the whole card, with the header
band's corners following it, so a host no longer wraps the control to get one.

**Released** 2026-09-25

**Minor.** The control renders differently and nothing in its API moves.

## The frame belongs with the layout

A host that wanted the About content to read as a card wrapped the control in a border of its own.
That border sits outside the header band, whose square corners then break out of the rounding, and
it has to be corrected whenever the card's own layout moves.

The control now draws the frame: a one-unit stroke in the stock card colour at a corner radius of
eight, with the header band taking the same radius on its top corners. No background, so a host on
a Mica window still shows the backdrop through the card's body.

The header keeps its fixed studio navy, which is deliberate and unchanged — only the corners it
stops at are new.

## In the popup

`BrandAboutWindow` shows the card framed, with its own "Check for Updates" button beneath the frame
rather than inside it. The button is the window's, not the card's, and it lines up with the card's
body padding as before.

## What a consumer has to change

Drop any border the page wrapped the control in, or the card is framed twice.

## Verifying it

Captured through the repository's harness in both themes, as the popup and as a control hosted in a
plain window; the pictures in [`zerozero-brand.md`](../../zerozero-brand.md) are the new ones.

## Unchanged

`AboutInfo`, `BrandAboutOptions`, the button row and its own buttons, the release-notes panel and
its fetch, the external-libraries list, the studio mark, the palette and the typeface. Both brand
assemblies release under the same number.
