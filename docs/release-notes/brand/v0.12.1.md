**A link with no browser to open it no longer ends the process, and a repopulated About page shows
only its own notes.**

**Released** 2026-10-11

**Patch.** Nothing a consumer compiles against moves. `ZeroZero.Brand.WinUI` takes
`ZeroZero.Win32` 0.9.2 and `ZeroZero.Controls.WinUI` 0.10.0.

## Fixed

- The Website, Donate and credit links catch a failure to start the shell. A machine with no handler
  for the address threw out of the click handler.
- `SetInfo` abandons a notes fetch still in flight, whose reply otherwise stored and showed the
  previous application's notes.
- Every raise of the About control's resize event logs a throwing handler. Only the raise after a
  fetch caught one.

## Changed

- `BrandAboutWindow` is built on the controls package's `ContentSizedPopup`. A first measure of zero
  opens the window at 200 units, and a resize after the window has closed does nothing.
