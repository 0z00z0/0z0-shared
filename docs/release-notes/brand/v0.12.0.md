**An About window opened before the taskbar exists no longer ends the process.**

**Released** 2026-10-11

**Minor.** `ZeroZero.Brand.WinUI` gains a mandatory package dependency on `ZeroZero.Controls.WinUI`
0.9.0, so a consuming repository's restore needs that package as well. No public member changes.

## Fixed

- `BrandAboutWindow` hides itself from the taskbar and Alt+Tab through the controls foundation
  assembly's `SwitcherVisibility.TrySet`. The plain setter throws `NotImplementedException` while no
  taskbar window exists, which ended the process from the window's constructor; measured on a
  desktop with no taskbar. The window now opens, and stays visible in the switchers in that case.

## What a consumer has to change

A repository that restores from the studio feed needs read access to `ZeroZero.Controls.WinUI` and,
through it, `ZeroZero.Primitives` and the Community Toolkit's settings controls. Nothing in code.
