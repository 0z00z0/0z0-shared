**The About page fetches its notes on every visit, and its credits and header follow the
application's own values.**

**Released** 2026-09-29

**Patch.** Nothing a consumer compiles against moves.

## Fixed

- A notes reply is applied only while its own fetch is current, and leaving the page abandons that
  fetch alone. A cached About page fetches the notes on every visit, including a leave-and-return
  before the first reply arrives.
- The external-libraries group is shown or collapsed from each `SetInfo` call's list, so it
  reappears when a later call supplies libraries.
- The About header reads `Brand.StudioName` and `Brand.Tagline` instead of fixed text.
- The `BrandAboutWindow` summary states when the window closes on dismissal, including the
  transient-window exception.
- The font-path release guard also reads `BrandBracketButton.xaml` and `UpdateWindow.xaml`.
- Comments and the brand guide state current behaviour only.
