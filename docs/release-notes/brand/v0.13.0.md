**The console banner and the About surface write their texts in the UI culture, with Norwegian built
in and the application's localizer asked first.**

**Released** 2026-10-23

**Minor.** Two methods take a new optional parameter and one option is added. Existing calls compile
unchanged; a library compiled against 0.12 that calls `ConsoleBanner.Print` or
`BrandAboutControl.SetInfo` is rebuilt against 0.13. Takes `ZeroZero.Primitives` 0.9.0,
`ZeroZero.Win32` 0.9.2 and `ZeroZero.Controls.WinUI` 0.11.0.

## Added

- **`ConsoleBanner.Print(info, strings)`** and **`BrandAboutControl.SetInfo(info, strings)`** take an
  optional `IStringLocalizer`, and **`BrandAboutOptions.Strings`** carries one for the About window.
  It is asked first for every key; a key it does not hold, or holds blank, falls to the component's
  own text.
- Texts in `Texts.resx` (en-GB) with Norwegian bokmål in `Texts.nb.resx`, in both assemblies, packed
  as `lib/<tfm>/nb/<Assembly>.resources.dll`: the banner's version line and libraries heading; on the
  About surface the version prefix, Website, Donate, What's new, the three release-notes messages,
  the libraries toggle in both states, the credit line, the copyright footer, Check for Updates, and
  the close button's screen-reader name, which is new.

## Changed

- `ZeroZero.Brand.Core` takes `ZeroZero.Primitives`.
- The application's own data is shown as supplied in every language: name, description, its own
  buttons, the credits and the release notes. The studio name and the tagline stay English.

## What a consumer has to change

- Nothing for an application that shows English or Norwegian. An application that translates its
  interface into another language passes its `IStringLocalizer` to `ConsoleBanner.Print`,
  `BrandAboutControl.SetInfo` or `BrandAboutOptions.Strings`.
- A host translation of the banner keys stays ASCII, a credit wording keeps `{0}` once for the
  library's link, and a translation of the libraries toggle keeps its arrows.
