**The brand moves to .NET 11 and Windows App SDK 2.7.0, the typeface becomes Cascadia Code, and slate joins the palette.**

**Released** 2026-11-19

**Minor, breaking.** The WinUI package targets `net11.0-windows10.0.26100.0` instead of `net10.0-windows10.0.26100.0` and `ZeroZero.Brand.Core` `net11.0` instead of `net10.0`, and the Windows App SDK under them moves from 2.4.0 to 2.7.0. Takes `ZeroZero.Primitives` 0.10.0, `ZeroZero.Win32` 0.10.0 and `ZeroZero.Controls.WinUI` 0.12.0.

## Changed

- **The brand typeface is Cascadia Code, with its ligatures, on every surface, body text included.**
  The packed font file is `CascadiaCode.ttf` under
  `lib/<tfm>/ZeroZero.Brand.WinUI/Assets/Fonts/`, beside the same OFL licence, and
  `BrandFontFamily` names the family `Cascadia Code`. The character set is the same 1483 code points
  as before, so a symbol chosen from the old face is still carried.

## Added

- **`Brand.ColorSlate`**, `#7388a0`, the studio's muted text colour, and `BrandSlateColour` with
  `BrandSlateBrush` in the resource dictionary. Under high contrast the slate keys follow the system
  highlight colour, as the other accents do.

## What a consumer has to change

- Target `net11.0-windows10.0.26100.0`, which the build kit's application block at 0.10.0 sets, and
  build with the .NET 11 SDK, 11.0.100 or later.
- **The Windows App SDK moves from 2.4.0 to 2.7.0.** An unpackaged application needs
  `Microsoft.WindowsAppRuntime.2` at 2.7.0.0 registered for the user; an installer that carries the
  runtime, and any prerequisite check written against 2.4.0, move to 2.7.0 with it. A self-contained
  publish carries the runtime in its own folder.
- A direct reference to a component named above rises to at least the version named, or the restore
  fails with `NU1605`.
- Raise `ZeroZero.Build` to 0.10.0 in the same change where the application takes the build kit.
  The kit pins the packages named above; an older kit pins them below what this release needs, and
  the restore fails with `NU1605`.
- **The .NET 11 desktop runtime is required on the end user's machine** for a framework-dependent
  application; a self-contained publish carries it.
- An application that names the font file or the family itself — a URI ending in
  `CascadiaMono.ttf#Cascadia Mono` — changes it to `CascadiaCode.ttf#Cascadia Code`, or takes
  `BrandFontFamily` instead. A URI left on the old file resolves to nothing and falls back silently.
- A published application carries `CascadiaCode.ttf`; an installer or file list that names
  `CascadiaMono.ttf` changes with it.
