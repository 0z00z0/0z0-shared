**The bracket action button centres itself in whatever width its host gives the control.** No
public member changes, and nothing about `BrandBracketButtonState` or the button's colours moves.

**Released** 2026-09-18

**Patch.** `Surface`, the real `Button` inside `BrandBracketButton`, carried no horizontal
alignment of its own, so it took the platform's default button placement — the left edge — inside
a control that otherwise sizes to its content. It now centres itself in that space.

## What moves, and what a host does about it

A host that places `BrandBracketButton` without setting alignment sees the button move from the
left edge of whatever width the control was given to the centre of it. A host that wants it back at
the start sets `HorizontalAlignment="Left"` on the control itself; a host that already set `Center`
on the control sees no change, since that is where the button already sat.

## Unchanged

`BrandBracketButton`'s public members, `BrandBracketButtonState`, its colours, its animation
timings and `Brand.cs` are unchanged. Nothing else in `ZeroZero.Brand.Core` or
`ZeroZero.Brand.WinUI` changes; both release under the same number.
