**A late Stop is honoured, a failed launch leaves no installer behind, and verification never
throws.**

**Released** 2026-09-29

**Patch.** One enum value is added; nothing is removed or renamed.

## Fixed

- Stop pressed while the installer is being verified keeps the installer from starting and removes
  the downloaded file.
- The unattended policy removes an installer that would not start, so retries leave no copies.
- The verifier returns the new `VerificationVerdict.FileUnreadable` where the downloaded file cannot
  be opened to be hashed, in place of throwing. A `switch` over the verdict without a default arm
  gains a case to handle.
- A shared update check runs under no caller's cancellation token; each caller waits under its own,
  so one caller cancelling no longer cancels another.
- Comments in the update and MQTT panels state present facts.
