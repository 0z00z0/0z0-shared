**An update window opened before the taskbar exists no longer ends the process.**

**Released** 2026-10-11

**Minor.** `ZeroZero.Update.WinUI` gains a mandatory package dependency on
`ZeroZero.Controls.WinUI` 0.9.0 and takes `ZeroZero.Brand.WinUI` 0.12.0, so a consuming
repository's restore needs the controls package as well. No public member changes.

## Fixed

- `UpdateWindow` hides itself from the taskbar and Alt+Tab through the controls foundation
  assembly's `SwitcherVisibility.TrySet`. The plain setter throws `NotImplementedException` while no
  taskbar window exists, which ended the process from the window's constructor. The window now
  opens, and stays visible in the switchers in that case.

## What a consumer has to change

A repository that restores from the studio feed needs read access to `ZeroZero.Controls.WinUI`.
Nothing in code.
