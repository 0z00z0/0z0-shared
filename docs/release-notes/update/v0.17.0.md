**Every text the update shows comes from resource files, with Norwegian built in and the
application's localizer asked first.**

**Released** 2026-10-23

**Minor, breaking.** `UpdateMessages` is no longer static, and two reason constants are removed.
Takes `ZeroZero.Primitives` 0.9.0, `ZeroZero.Win32` 0.9.2, `ZeroZero.Controls.WinUI` 0.11.0 and
`ZeroZero.Brand.WinUI` 0.13.0.

## Added

- Texts in `ZeroZero.Update.Win32`'s `Texts.resx` (en-GB) with Norwegian bokmål in `Texts.nb.resx`,
  packed as `lib/<tfm>/nb/ZeroZero.Update.Win32.resources.dll`. The UI culture picks the language;
  sizes and the rate-limit time follow the regional format, as before.
- An optional **`Strings`** localizer, asked first by key, on `UpdateWindowOptions` (everything the
  window shows), `InstallHolds` (`HoldUnreadable`) and `UnattendedUpdateOptions` (`MachineInUse` and
  `InstallerRunning`). Null, the default, asks nothing.
- **`UpdateMessages.HoldUnreadable`**, **`UpdateMessages.MachineInUse`** and
  **`UpdateMessages.InstallerRunning`**, the reason clauses the holds and the unattended path give.
- The update window's close cross has a screen-reader name, the same word as the Close button.

## Changed

- **`UpdateMessages` is a class over an optional `IStringLocalizer`**: `new UpdateMessages()` or
  `new UpdateMessages(localizer)`. The former constants are read-only properties and the former
  static methods are instance methods, under the same names.
- The guide's section on holding an install states that a hold stops both paths, the installation a
  person starts from the update window included. A condition for the automatic path alone goes in
  `UnattendedUpdateOptions.MayDownloadNow`, which only that path asks; a release is then reported but
  not downloaded in the background.

## Removed

- `InstallHolds.Unreadable`, replaced by `UpdateMessages.HoldUnreadable`.
- `UnattendedUpdatePolicy.MachineInUse`, replaced by `UpdateMessages.MachineInUse`.

## What a consumer has to change

- Construct `UpdateMessages` before reading from it: `new UpdateMessages()`, or
  `new UpdateMessages(localizer)` with the application's own `IStringLocalizer`. The members keep
  their names; a former constant is now a read-only property and a former static method an instance
  method.
- Replace `InstallHolds.Unreadable` with `UpdateMessages.HoldUnreadable`, and
  `UnattendedUpdatePolicy.MachineInUse` with `UpdateMessages.MachineInUse`.
- `UpdateMessages.InstallerRunning` is new and available where the application compares or shows
  that reason.
- An application that translates its interface passes its localizer as `Strings` on
  `InstallHolds`, `UnattendedUpdateOptions` and `UpdateWindowOptions`. A hold reason the application
  writes in Norwegian follows "fordi", so it is written in subordinate word order.
