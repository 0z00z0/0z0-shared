**The watchdog's restart limit is counted through the primitives package's timestamp file.**

**Released** 2026-10-11

**Patch.** No behaviour changes. Takes `ZeroZero.Primitives` 0.8.0.

## Changed

- `WatchdogRestartLimiter` reads and writes its file of restart moments through
  `TimestampListFile`. The file's format is unchanged.
- The startup task and the watchdog task build their base definition and register through one shared
  routine. What counts as drift is unchanged.
